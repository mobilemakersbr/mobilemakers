# Aula 24: Explorar e Filtros de Descoberta

## Objetivo
Melhorar a navegabilidade do marketplace através de uma página de descoberta focada em categorias visuais.

## Conteúdo Teórico
- **UX de Descoberta:** Por que o "Explorar" é diferente da busca comum.
- **Filtros Dinâmicos:** Usando estados do React para filtrar dados do banco em tempo real.

## Atividade Prática
1. Criar cards de categoria com imagens de fundo (Layout Premium).
2. Integrar a busca global com os filtros de categorias.
3. Ajustar o `BottomNav` para a nova estrutura de navegação.

## Desafio
"Tente fazer o filtro de categorias funcionar sem recarregar a página. A fluidez é o que separa um app amador de um profissional."
