# Aula 22: Upload de Avatares e Storage

## Objetivo
Dominar o Supabase Storage para permitir que os usuários personalizem sua aparência no app.

## Conteúdo Teórico
- **Buckets:** Organizando arquivos (avatars vs photos).
- **Client-Side Upload:** Como enviar arquivos diretamente do navegador para a nuvem com segurança.
- **RLS no Storage:** Protegendo quem pode subir e quem pode ver os arquivos.

## Atividade Prática
1. Criar o bucket `avatars` no Supabase.
2. Implementar o `ProfileForm` com o componente de upload de imagem.
3. Garantir que a URL pública do avatar seja salva no banco de dados.

## Dica Pro
"Sempre mostre um 'preview' da imagem para o usuário antes de fazer o upload. Isso melhora a percepção de velocidade do seu app!"
