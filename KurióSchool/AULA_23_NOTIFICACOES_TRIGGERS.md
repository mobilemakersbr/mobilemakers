# Aula 23: Notificações Inteligentes e Triggers

## Objetivo
Criar um sistema de engajamento que avisa os usuários sobre curtidas e comentários sem precisar de um servidor backend complexo.

## Conteúdo Teórico
- **Database Functions:** O poder do PL/pgSQL dentro do Supabase.
- **Triggers:** Como reagir a mudanças nos dados (INSERT/UPDATE) em tempo real.

## Atividade Prática
1. Criar a tabela `notifications`.
2. Escrever a função de gatilho para Likes e Comentários.
3. Construir a página de "Atividade" (`/notifications`) que consome esses dados.

## Frase do Dia
"O melhor código é aquele que roda sozinho no banco de dados enquanto você dorme. Isso é escalabilidade!"
