# 🏫 Protocolo KurióSchool: Documentação de Aula

Este documento define o padrão de saída para cada etapa do projeto MobileMakers.

## 📋 Protocolo de Saída

1. **Status do Print:** Indicação de qual tela o usuário deve capturar (ex: "Print 01: Instalação GSD").
2. **Explicação Técnica:** Resumo do que foi feito na etapa.
3. **Deep Dive Code:** Explicação das linhas de código principais e lógica aplicada.
4. **Stack Tecnológica:** Listagem de Ferramentas, APIs e Bibliotecas utilizadas.
5. **Próximo Passo:** O que faremos a seguir.
