# 🧪 Estratégia de Testes

## Tipos de Teste
1. **Unitários/Integração:** Validação de componentes e funções utilitárias.
2. **E2E (End-to-End):** Fluxos críticos (Login -> Upload -> View Feed).
3. **UAT (User Acceptance Testing):** Verificação manual via guia KurióSchool.

## Ferramentas
- **Framework:** Playwright (E2E)
- **Runner:** Vitest
- **Manual:** Checklists em cada aula da KurióSchool.

## Cobertura Crítica
- Sucesso no Upload (Storage + DB).
- Persistência de Sessão (Cookies).
- Navegação Responsiva (Bottom Nav).
