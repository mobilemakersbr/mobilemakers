# 📜 Convenções de Código

## Nomenclatura
- **Componentes:** PascalCase (ex: `ImageGrid.tsx`)
- **Arquivos de Rota:** `page.tsx`, `layout.tsx` (Padrão Next.js)
- **Funções/Variáveis:** camelCase
- **CSS:** Tailwind CSS inline.

## TypeScript
- Preferência por `interface` para objetos de dados.
- Tipagem rigorosa em Server Actions.

## Estilo
- Uso de `lucide-react` para todos os ícones.
- `shadcn/ui` como base para novos componentes.
- Estética focada em Dark Mode por padrão (Violet/Indigo).

## Git
- Commits semânticos.
- Estrutura de branchs focada em fases (ex: `phase-01-auth`).
