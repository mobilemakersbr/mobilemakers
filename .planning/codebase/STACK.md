# 🛠️ Stack Tecnológica

## Core
- **Framework:** Next.js 14.2 (App Router)
- **Runtime:** Node.js 18+
- **Linguagem:** TypeScript 5.x
- **Estilização:** Tailwind CSS

## Componentes UI
- **Base:** shadcn/ui
- **Biblioteca:** Radix UI
- **Ícones:** Lucide React

## Backend & Infra
- **Auth/DB/Storage:** Supabase
- **Deployment:** Vercel

## Tooling
- **Package Manager:** NPM
- **Linting:** ESLint
- **Testing:** Vitest + Playwright (E2E)
