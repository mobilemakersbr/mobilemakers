# Phase 1 Context: Setup e Estrutura Base

## Domain
Setup inicial do projeto Next.js, configuração do Design System Mobile-First e criação do Layout base com navegação inferior.

## Implementation Decisions
- **D-01: Linguagem:** TypeScript (para maior segurança e produtividade).
- **D-02: Componentes:** shadcn/ui (gratuito, customizável e token-efficient).
- **D-03: Tema:** Dark Mode por padrão (estética premium).
- **D-04: Navegação:** Bottom Navbar (otimizado para uso com o polegar).
- **D-05: Estrutura:** Next.js 14 App Router (`/src` directory).
- **D-06: Estilização:** Tailwind CSS (nativo do shadcn).

## Specifics
- Seguir a estética "UGC" (User Generated Content) - clean, funcional, focada no conteúdo.
- Preparar para integração futura com Supabase (sem configurar agora).
