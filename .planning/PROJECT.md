# Project: MobileMakers

**Visão:** Banco de imagens e vídeos Mobile-First focado em estética UGC.

## Contexto

O MobileMakers resolve a falta de conteúdo autêntico (vertical/mobile) para gestores de tráfego e criadores. É um PWA de alta performance focado em SEO de imagem e licenciamento simplificado.

## Tecnologias (Stack)

- **Frontend:** Next.js 14 (App Router)
- **Estilização:** Tailwind CSS
- **Backend/Auth/DB:** Supabase
- **Storage:** Vercel Blob / Cloudinary
- **Pagamentos:** Stripe

## Requisitos Principais (Hypotheses)

- [ ] Galeria estilo Pinterest (Feed Infinito).
- [ ] Busca por modelo de dispositivo (EXIF Data).
- [ ] Licenciamento via PIX com download imediato.
